## facts
- Target version: cc65 toolchain 2.19 or later, providing `ca65` (assembler) and `ld65` (linker).
- Source is two-stage: `ca65` emits relocatable `.o` files, `ld65` links them into the final `.prg`.
- For the C64 target, `ld65 -t c64 -o out.prg src.o` uses the bundled `c64.cfg` and emits a `.prg` with 2-byte load-address header (`$0801`).
- Custom memory/segment layouts MUST use a `.cfg` linker script with `MEMORY {}` and `SEGMENTS {}` sections.
- Mnemonics are case-insensitive by default; labels are case-sensitive.
- Comments use `;` to end of line.

## directives
| directive | purpose | example |
|---|---|---|
| `.setcpu "<cpu>"` | Select CPU (`"6502"`, `"6502X"`, `"65C02"`, `"65816"`) | `.setcpu "6502"` |
| `.org <expr>` | Set absolute origin (rarely used with linker) | `.org $0801` |
| `.segment "<name>"` | Switch active segment | `.segment "CODE"` |
| `.code` / `.data` / `.rodata` / `.bss` / `.zeropage` | Shorthand segment switches | `.code` |
| `.byte <list>` / `.byt` | Emit 8-bit values | `.byte 1, 2, 3` |
| `.word <list>` | Emit 16-bit little-endian | `.word $0801` |
| `.dword <list>` | Emit 32-bit values | — |
| `.res <n>[, <fill>]` | Reserve `n` bytes (default zero) | `.res 256, 0` |
| `.asciiz "<str>"` | Emit string + zero terminator | `.asciiz "HELLO"` |
| `.byte "<str>"` | Emit raw string bytes (no terminator) | `.byte "HI"` |
| `.include "<file>"` | Include another source file | `.include "macros.inc"` |
| `.incbin "<file>"[, <off>[, <size>]]` | Embed raw binary | `.incbin "sprite.bin"` |
| `.import <sym>` | Reference symbol defined elsewhere | `.import _main` |
| `.export <sym>` | Make local symbol visible to linker | `.export start` |
| `.global <sym>` | Import-or-export shorthand | `.global table` |
| `.macro <name> [<params>] … .endmacro` | Define macro | — |
| `.scope <name> … .endscope` | Named local scope | — |
| `.proc <name> … .endproc` | Scoped procedure with implicit export | — |
| `.struct <name> … .endstruct` | Record layout | — |
| `.enum <name> … .endenum` | Enumeration | — |
| `.if <expr>` / `.else` / `.endif` | Conditional assembly | — |
| `.repeat <count>[, <var>] … .endrepeat` | Compile-time loop | — |
| `.define <name>(<args>) <body>` | Token-replacement macro | — |
| `.feature <name>` | Enable syntax feature | `.feature labels_without_colons` |

## segments
| segment | typical use | default placement in `c64.cfg` |
|---|---|---|
| `ZEROPAGE` | Zero-page scratch (`$02-$7F` user-safe range) | `$0002-$001A` (cc65 runtime range) |
| `STARTUP` | Startup code (BASIC SYS stub) | `$0801` |
| `LOWCODE` / `INIT` | Initialization code | linker-defined |
| `CODE` | Main program code | follows `STARTUP` |
| `RODATA` | Read-only data / constants | after `CODE` |
| `DATA` | Initialized read/write data | after `RODATA` |
| `BSS` | Uninitialized data (zero on start) | follows `DATA` |

## linker-config
- Default invocation for a simple `.prg`: `ld65 -t c64 -o out.prg src.o c64.lib`.
- The `-t c64` flag pulls in the bundled `c64.cfg` and `c64.lib` (the runtime that emits the BASIC SYS stub at `$0801`).
- For raw `.prg` with no cc65 runtime, supply a custom `.cfg`:

```
MEMORY {
    ZP:   start = $0002, size = $001A, type = rw, define = yes;
    LOAD: start = $07FE, size = $0002, type = ro, file = %O, fill = yes;
    MAIN: start = $0801, size = $7800, type = rw, file = %O;
}
SEGMENTS {
    LOADADDR: load = LOAD, type = ro;
    EXEHDR:   load = MAIN, type = ro, define = yes;
    CODE:     load = MAIN, type = ro;
    RODATA:   load = MAIN, type = ro;
    DATA:     load = MAIN, type = rw;
    BSS:      load = MAIN, type = bss, define = yes;
    ZEROPAGE: load = ZP,   type = zp;
}
```

- Invoke with `ld65 -C custom.cfg -o out.prg src.o`.

## labels
- Cheap local labels start with `@` and are scoped to the surrounding non-local label.
- Unnamed labels: `:` defines, `:+` / `:-` reference next/previous (chain with `:++` etc.).
- Use `.proc` / `.scope` for named local namespaces.

## examples
Minimal hand-rolled SYS stub (no cc65 runtime):

```
.segment "STARTUP"
    .word $080b              ; next line link
    .word 10                 ; line number
    .byte $9e, "2061", 0     ; SYS 2061
    .word 0                  ; end-of-program

.segment "CODE"
    lda #0
    sta $d020
    rts
```
